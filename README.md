# 🩺 Pensum Interactivo - Medicina

Aplicación web interactiva que permite visualizar el pensum académico del programa de Medicina de la Universidad Simón Bolívar, con acceso a los PAC (Programas Académicos de Curso) de cada asignatura.

---

🚀 Características

- 📚 Visualización por semestres (1 a 12)
- 🔍 Búsqueda en tiempo real de asignaturas
- 📄 Acceso directo a documentos PAC en PDF
- 🎯 Soporte para materias electivas con múltiples opciones
- 💡 Interfaz moderna e interactiva
- 📊 Contador dinámico de asignaturas y PAC disponibles

---

🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla)
- Google Fonts

---

📦 Instalación

1. Clona el repositorio:

```bash
git clone https://github.com/tuusuario/pensum-medicina.git
cd pensum-medicina
```
